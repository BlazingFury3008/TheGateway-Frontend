# The Gateway Frontend

The Gateway is a web companion for tabletop role-playing groups that play asynchronously on Discord. Players and game masters write their scenes in Discord and use The Gateway to manage characters, track downtime, and revisit past scenes.

## Current status

The frontend is in early development. Players can create an account through the signup page. Login and the tools for play are still to come.

## Planned features

- **Character creation.** Build characters with guidance from the rules of your game system, with the option to turn off rules enforcement. Vampire: The Masquerade 20th Anniversary Edition (V20) is the first planned system, with more to follow.
- **Character profiles.** Keep each character’s identity, backstory, and game details together for reference during play.
- **Downtime.** Submit downtime actions for your game master to review. The Gateway handles any required dice rolls, and the game master decides whether to approve the action.
- **Scene viewing.** Read play-by-post scenes from Discord in The Gateway.
